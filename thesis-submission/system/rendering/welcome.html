WHAT THIS IS

Thank you for taking part.
This system turns a physical arrangement on a table into a 3D scene.
01
The objects on the table are tracked. Each one can be linked to a generated 3D element.
02
Language is used to say what each object represents, and to change the scene as a whole.
You will use it twice today, once with each way of entering language.
02

SETTING UP

Before you start, the system has to learn your objects. This takes a couple of minutes and I will run it.
FIRST
I set up the table with nothing on it. The system measures the surface so it knows what is flat and what is an object.
THEN
You place the objects you want to use on the table. Spread them out so they are not touching.
THEN
Keep your hands away from the table for about half a minute. The system watches each object from different angles and learns its shape, so it can tell them apart later.
ONCE THAT IS DONE
You can pick objects up, move them, and put them back down. The system will keep track of which is which.
If it ever loses track of an object, push the objects apart and separate them again, and tell me.
03

THE PHYSICAL OBJECTS

01
Where you place an object on the table is where its linked element appears in the scene.
02
Move the object and the element moves with it.
03
When two assigned objects are close together, the system may respond to that relationship.
04
The physical size of an object does not set the size of the element it represents. A small object can become a large thing in the scene.
04

LANGUAGE

TEXT INPUT
Language does two jobs. It says what an object represents, and it changes the scene as a whole.

To say what an object represents, put its number in the first box and what it represents in the second, then press Assign.

object number: 1 meaning: a car

To set how big it appears, end the meaning with the word scale and a size.

meaning: a car scale large

To change the scene, type an instruction into the scene box and press enter.

make it darker add mist

You can change anything at any point. Assigning object 1 again gives it a new meaning.

The sizes are: tiny, miniature, small, big, large, huge. Without one, a default size is used.
The size you choose has nothing to do with the physical object on the table. A small object can be scale huge.
VOICE INPUT
Language does two jobs. It says what an object represents, and it changes the scene as a whole.
Hold the touchpad on the controller while you speak. Release it when you finish.

To say what an object represents, say the word object, then its number, then is, then what it represents.

"object 1 is a car"

To set how big it appears, end with the word scale and a size.

"object 1 is a car scale large"

To change the scene, just say the instruction.

"make it darker" "add mist"

You can change anything at any point. Saying object 1 is something else gives it a new meaning.

The sizes are: tiny, miniature, small, big, large, huge. Without one, a default size is used.
The size you choose has nothing to do with the physical object on the table. A small object can be scale huge.
After you speak, the transcript appears on screen and is read back to you. Hold the touchpad again and say yes to accept it, or no to try again.
05

WHAT TO EXPECT

01
Some actions finish immediately. Others take longer.
02
Making a new 3D element can take a while. The screen shows which stage it has reached.
03
Results vary. What appears may not be exactly what you pictured.
04
Wait for the current action to finish before starting another.
05
If an input is not accepted, try it again.
06
If something is not as you wanted, change it or adjust it with the controls.
07
These behaviours are part of the system you are looking at today.
06

THE TASK

Use the system to build a 3D scene of your choosing.

There is no target scene and no preferred outcome.

Work in whatever order makes sense to you. Change direction whenever you want.

Please use language as part of your process. What you say or type is up to you.

We are looking at how you work with the system, not at your artistic ability.
